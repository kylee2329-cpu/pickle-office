# 🧸 6인 캐릭터 시트 — 3등신 아기자기 피규어 (v4.2)

합동 비서실(pickle-office) 3D 오피스 맵에 서는 6인 비서의 **통일 규격 캐릭터 시트**입니다.
캐릭터는 `app.js`의 `CHARS`(이름·직함·시그니처 컬러·방)를 따르고, 얼굴은 `assets/avatars/<id>.png`(세미리얼리즘 20대 초중반 여성)를 계승합니다.
맵 위의 형태는 **2.5D 스탠드 피규어** — 3D 원형 받침대 위에 세운 투명 PNG 일러스트가 매 프레임 Y축 빌보드로 카메라를 바라봅니다.

## 1. 공통 규격 (6인 전원 동일)

| 항목 | 규격 |
|---|---|
| 비율 | **3등신** (머리 : 몸통 : 다리 ≒ 1 : 1 : 1). 머리를 크게, 몸통을 콤팩트하게 |
| 화풍 | 세미리얼리즘 소프트 3D 넨도로이드/클레이 피규어. 매트한 클레이 재질, 부드러운 스튜디오 조명, 바닥 그림자 없음 |
| 얼굴 | `assets/avatars/<id>.png`의 이목구비·헤어·피부톤 계승. 크게 뜬 눈, 작은 코·입, 은은한 블러시 |
| 체형 | 어깨 좁은 콤팩트 바디, 가는 팔·다리, 키 차이 거의 없음(맵에서 옹기종기) |
| 포즈 | 정면, 두 발 모으고 차렷. 소품은 가슴 앞에서 두 손으로 들거나 한 손에 자연스럽게 |
| 배경 | 순백 `#FFFFFF` 단색, 그림자·바닥선·텍스트 없음 (컷아웃용) |
| 출력 | 1024×1536 PNG 원본 → 컷아웃 후 높이 900px 투명 PNG |
| 받침대 | 3D 원형 받침대: **크림 베이스(`#fdf6e9`) + 각자 시그니처 컬러 밴드·림** + 얇은 이너 링, 앞쪽에 작은 명찰 |
| 맵 높이 | 월드 단위 **1.78~1.85** (아래 §3 표의 값). 폭은 이미지 종횡비 자동 반영 |
| 회전 | Y축 빌보드(항상 카메라 정면), 걷기 중에는 진행 방향을 보되 스탠드만 카메라를 추종 |

## 4. 동작 규격 (맵에서 6인 공통)

- **Y 빌보드**: 매 프레임 카메라 방향으로 Y축 회전. 걷는 동안에도 스탠드는 카메라를 향합니다.
- **클릭 레이캐스트**: 투명 PNG의 알파 여백을 클릭하면 뒤쪽 캐릭터가 선택되도록 `alphaTest` 기반 히트 영역 유지.
- **숨쉬기 / 걷기**: 숨쉬기는 평면 전체를 아래에서 위로 1.8% 스케일, 걷기는 살짝 튀는 바운스 + 좌우 기울기(스탠드 특성상 다리 스윙은 생략).
- **라운지 액션**: `⛳` 골프(퍼터), `🎾` 테니스(라켓+공), `☕` 커피(머그) 소품이 오른손 위치에 붙어 6인 전원 동작. 소품 위치는 이미지 폭 기준으로 자동 배치.
- **선택 링**: 발밑 시그니처 컬러 링(선택 시 점멸).

## 5. 생성·교체 절차 (재현용)

1. 아바타를 베이스로 3등신 피규어 생성 (아래 프롬프트 템플릿):
   ```
   images 'cute chibi SD figurine of this exact same young Korean woman, 3-head-to-body ratio with slightly larger cute head and adorable compact body, semi-realistic soft 3D Nendoroid/clay-figure aesthetic keeping her exact pretty face and <헤어>, wearing <의상>, <신발>, holding <소품>, standing straight facing forward from head to shoes, centered, pure solid #FFFFFF white background, studio lighting, no floor shadow, no text' --edit assets/avatars/<id>.png --out downloads/chibi-<id>-raw.png
   ```
2. 눈으로 확인: 잘림 없음 / 얼굴 닮음 / 순백 배경.
3. 컷아웃: `python3 tools/standee_cutout.py --src downloads/chibi-<id>-raw.png --out assets/standees/<id>.png` (6인 일괄은 `--all`)
4. `office3d.js`의 `STANDEE` 표에 높이·색만 추가하면 맵에 반영됩니다(이미지 종횡비는 로드 시 자동).
5. `index.html`의 `office3d.js?v=...`와 스탠드 텍스처 쿼리(`?v=`)를 함께 올려 캐시를 비웁니다.
